# 📇 초간편 모바일 명함 제작 시스템 (명함 스킬 키트)

이 시스템은 복잡한 코딩이나 HTML 수정 없이, **명함 이미지 교체와 텍스트 입력 단 2단계만으로 3분 만에 무결점 모바일 명함을 제작**할 수 있도록 설계된 표준 템플릿입니다.

---

## 🚀 3분 완성 제작 방법 (딱 2단계!)

### 1단계: 실물 명함 이미지 넣기
* 새로 제작할 실물 명함 이미지(앞면)를 준비합니다.
* 파일 이름을 **`card.png`** 로 변경한 뒤, **`images/`** 폴더 안에 덮어씌워 넣습니다.

### 2단계: `명함설정.js` 파일 열고 텍스트 수정하기
* 메모장이나 에디터로 **`명함설정.js`** 파일을 엽니다.
* 명함 이미지에 적힌 내용을 따옴표(`""`) 안에 적어줍니다.

```javascript
const CARD_DATA = {
  name: "홍길동",                           // 이름
  title: "영업팀장",                         // 직함
  company: "대한생명 강남금융지점",           // 회사명/소속
  phone: "010-1234-5678",                  // 휴대폰 번호
  email: "gildong@naver.com",              // 이메일
  locationTitle: "강남금융지점 사무실 위치",   // 위치 제목
  address: "서울특별시 강남구 테헤란로 123",  // 주소
  
  // 온라인 링크 (없으면 "" 빈칸으로 두면 화면에서 알아서 숨겨집니다)
  websiteUrl: "",                          // 홈페이지
  openKakaoUrl: "https://open.kakao.com/...", // 카카오 오픈채팅
  blogUrl: "",                             // 블로그
  youtubeUrl: "",                          // 유튜브
  shareUrl: ""                             // 배포 후 인터넷 주소
};
```

**끝입니다! 🎉**  
더 이상 `index.html`이나 `script.js`의 복잡한 코드를 건드릴 필요가 없습니다.

---

## ⚡ 자동으로 처리되는 핵심 기능들

1. **👆 명함 이미지 원터치 전화 걸기**
   - 명함 이미지 어디를 눌러도 설정한 전화번호로 즉시 다이얼이 열립니다.
2. **🗺️ 네이버 지도 길찾기 자동 생성**
   - 주소만 입력하면 네이버 지도 길찾기 링크가 자동으로 생성됩니다.
   - **카카오톡 인앱 브라우저 호환성**이 적용되어 카톡에서 열어도 외부 네이버 지도 앱으로 안전하게 연결됩니다.
3. **👤 원터치 스마트폰 주소록 저장 (vCard)**
   - 별도 파일 업로드 없이, 최신 vCard 3.0 규격 연락처가 실시간 생성되어 스마트폰 주소록에 바로 추가됩니다.
4. **📍 주소 터치 원터치 복사**
   - 주소를 누르면 클립보드에 복사되고 상단에 안내 토스트 팝업이 뜹니다.
5. **📞 화면 하단 고정 전화 플로팅 버튼**
   - 스크롤을 내려도 항상 하단에 통화 버튼이 고정되어 높은 상담 전환율을 보장합니다.
6. **🧹 스마트 자동 숨김**
   - 블로그나 유튜브가 없는 분은 버튼이 빈칸으로 남지 않고 화면에서 깔끔하게 사라집니다.

---

## 📁 폴더 구성 안내

* **`명함설정.js`** : 사용자가 내용을 수정하는 유일한 설정 파일
* **`images/card.png`** : 실물 명함 이미지 파일
* **`index.html`** : 모바일 최적화 웹 화면 구조
* **`style.css`** : 세련된 프리미엄 모바일 디자인
* **`script.js`** : 자동 데이터 매핑 및 카카오톡/지도 연동 엔진
* **`에러_해결_사전.md`** : 문제 발생 시 1초 만에 확인하는 해결 가이드
